## 📖 About

A **production-ready**, full-stack portfolio website designed specifically for AI Developers and Data Scientists. Built with modern technologies and featuring a stunning glassmorphism design with teal & coral theme.

### ✨ Why This Portfolio?

- 🎨 **Modern Design** - Glassmorphism effects, smooth animations, and responsive layout
- 🔐 **Admin CMS** - Manage all content without touching code
- ⚡ **Lightning Fast** - Built with FastAPI for optimal performance
- 📱 **Mobile First** - Perfectly responsive on all devices
- 🌓 **Dark/Light Mode** - Automatic theme switching
- 🔌 **API-Driven** - RESTful architecture for easy integration
- 📊 **GitHub Integration** - Auto-fetch and display your repositories
- 🚀 **Deploy Ready** - Multiple deployment options included

## 🚀 Quick Start

### Prerequisites

```bash
Python 3.11+
pip
Git
```

### Installation

1️⃣ **Clone the repository**
```bash
git clone https://github.com/asiifkarim/Asif_Karim_Portfolio_website.git
cd Asif_Karim_Portfolio_website
```

2️⃣ **Create virtual environment**
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

3️⃣ **Install dependencies**
```bash
cd backend
pip install -r requirements.txt
```

4️⃣ **Run the backend**
```bash
python app.py
```
Backend will start at `http://localhost:8000`

5️⃣ **Run the frontend** (new terminal)
```bash
cd frontend/src
python -m http.server 3000
```
Frontend will start at `http://localhost:3000`

### 🎉 Access Your Portfolio

- **Website:** http://localhost:3000/index.html
- **Backend API:** http://localhost:8000
- **API Docs:** http://localhost:8000/docs
- **Admin Panel:** http://localhost:8000/admin/login

**Default Admin Credentials:**
```
Username: admin
Password: admin123
```
⚠️ **Change immediately after first login!**

### Deployment Steps (Render - Recommended)

1. **Backend Deployment:**
   - Create account on [Render](https://render.com)
   - New Web Service → Connect GitHub repo
   - Root Directory: `backend`
   - Build: `pip install -r requirements.txt`
   - Start: `uvicorn app:app --host 0.0.0.0 --port $PORT`

2. **Frontend Deployment:**
   - New Static Site → Same repo
   - Root Directory: `frontend/src`
   - Publish Directory: `.`

3. **Configure:**
   - Add environment variables to backend
   - Update `frontend/src/config.js` with backend URL
   - Push changes

📚 **Detailed Instructions:** See [GITHUB_DEPLOYMENT_GUIDE.md](GITHUB_DEPLOYMENT_GUIDE.md)

## 🔧 Configuration

### Environment Variables

Create `backend/.env` file:

```env
# Server
PORT=8000

# Security (Generate: python -c "import secrets; print(secrets.token_hex(32))")
SECRET_KEY=your-super-secret-key-here

# CORS
ALLOWED_ORIGINS=http://localhost:3000,https://your-frontend-url.com

# GitHub Integration
GITHUB_USERNAME=asiifkarim
```

### Frontend Configuration

Update `frontend/src/config.js`:

```javascript
const CONFIG = {
    BASE_URL: 'http://localhost:8000',  // Change to production URL
    // ...
};
```

## 📚 API Documentation

### Public Endpoints

```http
GET  /api/projects        # Fetch GitHub repositories
GET  /api/blogs          # Get published blog posts
GET  /api/profile-image  # Get profile image URL
POST /api/contact        # Submit contact form
GET  /health             # Health check
```

### Admin Endpoints (Requires JWT)

```http
POST   /api/auth/login              # Admin login
GET    /api/auth/me                 # Get current user
POST   /api/admin/images/upload     # Upload image
GET    /api/admin/images            # List images
DELETE /api/admin/images/{id}       # Delete image
POST   /api/admin/projects          # Create project
PUT    /api/admin/projects/{id}     # Update project
DELETE /api/admin/projects/{id}     # Delete project
POST   /api/admin/blogs             # Create blog
PUT    /api/admin/blogs/{id}        # Update blog
DELETE /api/admin/blogs/{id}        # Delete blog
```

**Interactive Docs:** Visit `/docs` for Swagger UI or `/redoc` for ReDoc

## 🎨 Customization

### Update Personal Information

1. **GitHub Username:** Edit `backend/api.py` or set `GITHUB_USERNAME` in `.env`
2. **Contact Info:** Update templates in `backend/templates/`
3. **Social Links:** Edit footer in `backend/templates/base.html`
4. **Profile Image:** Upload via admin panel
5. **About Content:** Edit `backend/templates/about.html`

### Customize Theme Colors

Edit `frontend/src/css/style.css`:

```css
:root {
  --primary-color: #0d9488;    /* Teal */
  --secondary-color: #f43f5e;  /* Coral */
  --accent-color: #06b6d4;     /* Sky Blue */
  /* Customize more colors... */
}
```
